# How to use the chatbot
### First, install the libraries
```bash
pip install requests minsearch pythainlp google-genai python-dotenv streamlit ipykernel
```
### Create a .env file in the root directory of this project then type your token or api here:
```bash
GEMINI_API_KEY=
```
### Run the Application:
```bash
python -m streamlit run Thaiapp.py
```
